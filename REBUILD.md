# Korean Core Starter — Svelte rebuild

The app is being rebuilt as a **Vite + Svelte** SPA at the repo root. The legacy vanilla app under
`korean/` still works and stays until cutover. All content lives in `korean/data/*.json` (generated by
`scripts/*.mjs`) and is reused unchanged.

## Develop
```bash
npm install          # once
npm run dev          # → http://localhost:5173/words/
npm test             # Vitest (34 tests)
```

## Refresh content (after editing seeds in scripts/)
```bash
node scripts/generate-korean-data.mjs            # words/expr/patterns/newcomer/vocab-extended + dialogues
node scripts/upgrade-korean-textbook-quality.mjs # course/grammar beginner explanations
node scripts/audit-korean-content.mjs            # integrity gate
node scripts/build-app-data.mjs                  # → korean/data/app-data.json (slim bundle the Svelte app imports)
```
`scripts/build-app-data.mjs` strips fields the new UI never renders (`lesson`, `formGroupInfo`,
`formLinks`, `contextHint`, `learnerPriority`, `activityTags`, `speechLevels`, `adjectiveForms`,
`chapterIds`) to keep the build small. **Always run it after `generate-korean-data.mjs`.**

## Build
```bash
npm run build        # → dist/  (base path /words/)
```
Output chunks: tiny app (`index` ~29KB gz + `vendor` ~6KB gz), data (`data` ~466KB gz, cached separately).

## Deploy / cutover to GitHub Pages (busanthebox.coder.github.io/words)
This working copy is **not a git repo**, so set that up first:
```bash
git init && git add -A && git commit -m "Svelte rebuild"
git remote add origin <your-words-repo-url>
npm run deploy       # builds + pushes dist/ to the gh-pages branch via gh-pages
```
Then point GitHub Pages at the `gh-pages` branch (or copy `dist/` to your Pages publish dir).
`vite.config.js` sets `base: '/words/'` so asset URLs match the repo subpath; hash routing avoids 404s
on refresh. Keep `korean/` reachable until the new build is verified, then make `dist/` the served root.
