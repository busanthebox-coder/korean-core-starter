# Korean Core Starter 사용 설명서

Korean Core Starter는 한국에서 바로 쓰는 한국어를 혼자 공부할 수 있게 만든 브라우저 앱입니다.  
문법을 외우는 앱이라기보다, 짧은 학습 세션 안에서 **보고, 따라 말하고, 문제를 풀고, 실제 상황에 다시 써보는 흐름**을 만들기 위한 자료입니다.

고품질 녹음 음성은 마지막 단계에서 보강할 예정입니다. 지금은 학습 흐름, 설명, 복습, 역할극, 사전, 생활 가이드가 핵심입니다.

## 1. 처음 시작하는 순서

처음 쓰는 사람은 아래 순서로 시작하면 됩니다.

1. `Guide` 탭을 엽니다.
2. `App Manual`을 먼저 봅니다.
3. `Set up Korean typing`에서 한국어 입력 준비를 확인합니다.
4. `How Korean Works`로 한국어의 기본 구조를 훑어봅니다.
5. `Learn` 탭에서 배치 테스트 또는 Chapter 1부터 시작합니다.
6. 한 챕터를 본 뒤 바로 `Practice this chapter`로 복습합니다.
7. 다음 날에는 `Practice` 탭에서 due review를 먼저 처리하고 새 챕터로 갑니다.

처음부터 모든 기능을 다 쓰려고 하지 않아도 됩니다.  
초반에는 `Learn -> Practice -> Shadow` 세 가지만 꾸준히 써도 충분합니다.

## 2. 하루 공부 루틴

짧게 자주 공부하려면 하루 10-15분을 기준으로 잡는 것이 좋습니다.

### 5분만 있을 때

1. `Practice` 탭에서 due review를 풉니다.
2. 틀린 항목이 있으면 해설만 읽고 끝냅니다.
3. 시간이 남으면 `Dictionary`에서 방금 틀린 표현을 검색합니다.

### 10분 있을 때

1. `Practice` 탭에서 due review를 먼저 합니다.
2. `Learn`에서 한 챕터의 대화와 핵심 설명을 읽습니다.
3. 챕터 안의 `Practice this chapter`를 풉니다.

### 20분 이상 있을 때

1. due review를 끝냅니다.
2. 새 챕터를 하나 진행합니다.
3. `Shadow`에서 관련 대화를 따라 말합니다.
4. `Roleplay`에서 비슷한 상황에 직접 답해봅니다.
5. 마지막에 오늘 헷갈린 표현 1-2개만 `Dictionary`에서 확인합니다.

중요한 순서는 항상 같습니다.

**복습 먼저 -> 새 내용 조금 -> 소리 내서 따라 하기 -> 실제 상황으로 바꿔보기**

## 3. 탭과 주요 화면 사용법

### Learn

`Learn`은 메인 교재입니다. 챕터별로 대화, 단어, 표현, 문법, 연습이 이어집니다.

추천 사용법:

1. 챕터 제목과 목표를 먼저 읽습니다.
2. `Warm-up Dialogue`를 봅니다.
3. 대화의 한국어 문장과 영어 뜻을 비교합니다.
4. 단어와 표현을 훑습니다.
5. 문법 설명에서 “왜 자연스러운지”를 읽습니다.
6. 챕터 연습을 풀고, 틀린 문제의 해설을 꼭 읽습니다.
7. 챕터가 너무 쉽다면 다음 챕터로 넘어갑니다.

초반에는 Romaja를 켜도 괜찮습니다.  
다만 Chapter 3 이후부터는 조금씩 Romaja를 끄고 한글을 직접 읽는 연습을 하는 것이 좋습니다.

### Today Plan

챕터 상단의 Today Plan은 그날 챕터를 어떤 순서로 처리할지 보여주는 카드입니다.

- `Dialogue`: 먼저 상황을 이해합니다.
- `Add items`: 오늘 배울 단어와 표현을 복습 목록에 넣습니다.
- `Practice`: 바로 문제로 확인합니다.
- `Complete`: 챕터를 마무리합니다.

완료 표시는 학습 흐름을 기억하기 위한 장치입니다. 완벽히 외웠다는 뜻은 아니므로, 이후 `Practice`에서 계속 다시 만나게 됩니다.

### Reading Room

Reading Room은 조금 긴 한국어 문장을 읽는 공간입니다.  
짧은 대화만 보면 실제 안내문, 공지, 앱 문구를 읽기 어려우므로, 중간중간 읽기 자료로 눈을 길들이는 용도입니다.

읽을 때는 모든 단어를 외우려고 하지 말고 다음만 확인합니다.

- 문장의 주제가 무엇인지
- 아는 표현이 어디에 있는지
- 모르는 단어가 문장 전체 이해를 막는지
- 실제 한국 생활에서 다시 볼 만한 문장인지

### Practice

`Practice`는 복습과 문제풀이 탭입니다.  
앱의 기억 시스템이 복습할 때가 된 항목을 다시 보여줍니다.

추천 순서:

1. due review가 있으면 먼저 풉니다.
2. 새 챕터를 공부한 날에는 해당 챕터 practice를 풉니다.
3. 많이 틀린 날에는 weak practice를 다시 합니다.
4. 시간이 짧은 날에는 Practice만 하고 끝내도 됩니다.

문제 유형은 여러 가지가 섞여 있습니다.

- 뜻 고르기
- 빈칸 채우기
- 문장 만들기
- 쓰기 연습
- 매칭
- 활용형 고르기
- 듣고 고르기

보기 중 비슷한 표현이 나오면 “뜻이 비슷한가”보다 “이 상황에서 어떤 말이 자연스러운가”를 기준으로 고릅니다.  
한국어는 같은 뜻처럼 보여도 상황, 친밀도, 말투, 상대의 나이에 따라 답이 달라질 수 있습니다.

### Shadow

`Shadow`는 대화를 따라 말하는 탭입니다.

추천 사용법:

1. 먼저 영어 뜻을 보면서 대화 상황을 이해합니다.
2. 한국어 문장을 눈으로 따라 읽습니다.
3. 한 줄씩 소리 내어 따라 말합니다.
4. `Practice mode`로 영어를 숨깁니다.
5. 막히는 줄만 다시 반복합니다.
6. 충분히 따라 했으면 `Mark done`으로 표시합니다.

Shadow의 목표는 완벽한 발음보다 **입에서 문장 리듬이 나오는 것**입니다.  
처음에는 느리게, 그다음에는 자연스러운 속도로 따라 합니다.

### Roleplay

`Roleplay`는 실제 상황처럼 답해보는 탭입니다.

이 탭은 정답 하나만 외우기 위한 곳이 아닙니다.  
식당, 병원, 길 찾기, 쇼핑, 약속, 업무 같은 상황에서 “내가 뭐라고 말할지”를 연습하는 공간입니다.

추천 사용법:

1. 상황을 읽습니다.
2. 힌트를 보기 전에 먼저 한 번 답합니다.
3. 너무 막히면 힌트를 봅니다.
4. 답을 확인한 뒤, 왜 그 표현이 자연스러운지 읽습니다.
5. 같은 상황을 내 생활에 맞게 바꿔서 한 번 더 말합니다.

예를 들어 “예약했어요”를 배웠다면, 다음처럼 바꿔 봅니다.

- 병원 예약했어요.
- 식당 예약했어요.
- 네이버로 예약했어요.
- 예약을 변경하고 싶어요.

이렇게 바꿔 말해야 실제 한국어로 넘어갑니다.

### Dictionary

`Dictionary`는 앱 안의 단어, 표현, 문법을 찾아보는 곳입니다.

좋은 사용법:

1. 방금 챕터에서 본 표현을 검색합니다.
2. 예문을 확인합니다.
3. 비슷한 말과 차이를 읽습니다.
4. 자주 틀리는 포인트를 확인합니다.
5. 정말 필요한 항목만 review에 추가합니다.

주의할 점:

- 사전을 처음부터 끝까지 읽으려고 하지 않습니다.
- 모든 단어를 복습에 넣지 않습니다.
- 지금 배우는 챕터와 관련 있는 단어부터 봅니다.
- 실생활에서 다시 쓸 가능성이 높은 표현을 우선합니다.

Dictionary는 “메인 교재”가 아니라 **헷갈릴 때 찾아보는 도구**입니다.

### Guide

`Guide`는 한국 생활과 앱 사용법을 모아둔 탭입니다.

주요 용도:

- 앱 사용법 확인
- 한국어 입력 준비
- 네이버, 배달, 병원, 은행 같은 생활 상황 보기
- 배치 테스트 다시 열기
- 한자 어근과 단어 관계 보기
- 내가 쓴 글 아카이브 확인
- 학습 기록 백업과 복원

한국에 처음 온 학습자는 `Guide`를 교재 중간중간 같이 보면 좋습니다.  
문법 챕터만 보면 실제 생활 앱, 안내문, 공공기관 표현이 낯설 수 있기 때문입니다.

## 4. 네이티브 도움을 받을 때

이 앱은 혼자 공부할 수 있게 설명을 제공하지만, 한국인 네이티브와 같이 볼 시간이 있다면 훨씬 좋아집니다.

다만 네이티브가 항상 문법 선생님처럼 설명할 수 있는 것은 아닙니다.  
그래서 역할을 나누는 것이 좋습니다.

앱이 맡는 것:

- 뜻 설명
- 문법 구조
- 비슷한 표현 차이
- 영어권 학습자가 자주 하는 실수
- 복습 순서

네이티브가 도와주면 좋은 것:

- 실제로 이 말을 쓰는지 확인
- 더 자연스러운 말투 제안
- 요즘 사람들이 자주 쓰는 표현
- 내 상황에 맞는 문장으로 바꾸기
- 발음과 억양 피드백

네이티브와 공부할 때는 이렇게 준비하면 좋습니다.

1. 이번 주에 배운 문장 3개를 고릅니다.
2. “이거 자연스러워?”라고 확인합니다.
3. 내 상황으로 문장을 바꿔봅니다.
4. 네이티브가 말한 자연스러운 버전을 기록합니다.
5. 그 표현을 `Dictionary`나 `Practice`에서 다시 확인합니다.

예시 질문:

- 이 문장 실제로 써요?
- 더 자연스럽게 말하면 어떻게 말해요?
- 친구한테 말할 때랑 직원한테 말할 때 달라요?
- 이건 너무 딱딱해요?
- 카톡으로 보내면 이상해요?

## 5. Romaja 사용법

Romaja는 처음 한글을 읽기 전까지의 보조 바퀴입니다.

좋은 사용법:

- Chapter 1-2: 켜고 봐도 괜찮습니다.
- Chapter 3-10: 먼저 한글을 보고, 막힐 때만 Romaja를 확인합니다.
- Chapter 10 이후: 가능하면 끄고 봅니다.

Romaja에 오래 의존하면 한국어 소리와 한글을 직접 연결하는 속도가 느려질 수 있습니다.  
특히 `eo`, `eu`, `ui` 같은 표기는 영어식으로 읽기 쉽기 때문에, 결국 한글 기준으로 넘어와야 합니다.

## 6. 복습과 완료 표시

앱에는 여러 종류의 완료 표시가 있습니다.

- 챕터 완료: 그 챕터를 한 번 끝냈다는 뜻입니다.
- Practice 완료: 해당 세션 문제를 풀었다는 뜻입니다.
- Shadow 완료: 그 대화를 따라 말해봤다는 뜻입니다.
- Guide 완료: 해당 가이드 내용을 확인했다는 뜻입니다.

완료는 “다 외웠다”가 아닙니다.  
학습 기록을 정리하기 위한 표시이고, 중요한 항목은 Practice에서 다시 나옵니다.

복습이 많이 밀렸을 때는 새 챕터를 많이 나가지 말고 due review를 먼저 줄이는 것이 좋습니다.

## 7. 백업과 기기 변경

학습 기록은 기본적으로 현재 브라우저에 저장됩니다.  
브라우저 기록을 지우거나 다른 기기로 옮기면 진도가 사라질 수 있습니다.

기기를 바꾸기 전에는 `Guide` 탭의 백업 기능을 사용합니다.

1. `Guide` 탭으로 갑니다.
2. 학습 기록 백업 카드를 찾습니다.
3. `Export`로 백업 파일을 저장합니다.
4. 새 기기나 새 브라우저에서 `Import`로 가져옵니다.

브라우저 캐시, 사이트 데이터, 로컬 저장소를 삭제하기 전에도 백업하는 것이 좋습니다.

## 8. 오프라인과 업데이트

앱은 한 번 로드한 뒤 일부 기능을 오프라인에서도 사용할 수 있게 설계되어 있습니다.  
다만 처음 접속할 때는 인터넷 연결이 필요합니다.

업데이트가 있을 때는 앱이 새 버전을 안내할 수 있습니다.  
화면이 이상하거나 예전 내용이 계속 보이면 새로고침을 해보고, 그래도 안 되면 브라우저 캐시를 지운 뒤 다시 접속합니다.

## 9. 문제 해결

### 진도가 사라졌어요

가능한 원인:

- 다른 브라우저로 접속했습니다.
- 시크릿 모드에서 사용했습니다.
- 사이트 데이터를 삭제했습니다.
- 다른 기기로 접속했습니다.

해결:

- 백업 파일이 있으면 `Guide`에서 Import합니다.
- 앞으로는 기기 변경 전에 Export를 해둡니다.

### 소리가 안 나요

현재 음성 기능은 브라우저의 Web Speech나 임시 음성에 의존하고 있습니다.
브라우저, OS, 네트워크 상태에 따라 소리가 다르게 재생될 수 있습니다.

해결:

- 음소거 상태인지 확인합니다.
- 다른 브라우저에서 열어봅니다.
- 페이지를 새로고침합니다.
- 고품질 녹음 음성은 마지막 단계에서 별도로 보강할 예정입니다.

### 한국어 입력이 안 돼요

`Guide > Set up Korean typing`을 먼저 확인합니다.

일반적으로 필요한 것은 다음입니다.

- 운영체제에서 Korean 입력기 추가
- 한/영 전환 키 확인
- 모바일 키보드에서 Korean 추가
- 받침 입력 연습

### Practice에 문제가 별로 안 떠요

복습할 항목이 아직 부족하거나, due review가 없는 상태일 수 있습니다.

해결:

- `Learn`에서 새 챕터를 하나 진행합니다.
- 챕터 안의 항목을 review에 추가합니다.
- `Dictionary`에서 필요한 표현만 review에 추가합니다.
- 다음 날 다시 Practice를 확인합니다.

### 너무 어려워요

챕터를 완벽히 끝내려고 하지 않아도 됩니다.

이렇게 줄여서 진행합니다.

1. 대화만 읽습니다.
2. 핵심 표현 3개만 고릅니다.
3. Practice를 조금만 풉니다.
4. 다음 날 다시 봅니다.

언어 공부는 한 번에 이해하는 것보다 여러 번 다시 만나면서 익숙해지는 쪽이 더 자연스럽습니다.

## 10. 추천 주간 루틴

### 주 5일 혼자 공부

- 월: 새 챕터 1개 + Practice
- 화: due review + Shadow
- 수: 새 챕터 1개 + Practice
- 목: due review + Dictionary 정리
- 금: Roleplay + 약한 항목 복습

### 주 2회 네이티브 도움을 받을 때

네이티브와 만나는 날:

1. 이번 주에 배운 표현 3개를 가져갑니다.
2. 실제로 자연스러운지 확인합니다.

## 11. 이 앱을 잘 쓰는 기준

좋은 사용 방식:
