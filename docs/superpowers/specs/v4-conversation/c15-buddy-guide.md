# C15 — 버디 세션 가이드 (죽은 buddyCard 살리기 + 주간 미션)

규모: 소~중. 의존 없음(C13 완료 후면 해요체 시나리오가 미션에 포함되어 더 좋음).
목표 한 줄: "주 2회 한국인 친구와 함께 본다"는 실제 사용 패턴을 앱의 1급 기능으로 만든다 —
친구는 선생님이 아니어도 되도록, 앱이 대본·설명·역할 안내를 다 준다.

## 실측 근거 (2026-07-17)
- **buddyCard가 전 Roleplay 시나리오 데이터에 존재하나 UI 렌더 0곳** (grep 확인 — 생성·검증 스크립트만 참조):
  ```json
  "buddyCard": {
    "instructionKo": "늦은 밤에 연락을 받은 친한 친구 역할을 해 주세요. 학습자는 초급이에요. 천천히 …",
    "reactionKo": "그랬구나… 혼자 많이 힘들었겠다."
  }
  ```
  instructionKo = 친구에게 폰을 건네 보여줄 역할 안내(한국어), reactionKo = 친구가 써도 좋은 모범 리액션.
- 사용자 요구사항(V3 브리핑): "네이티브는 선생님이 아니므로 '왜 자연스러운지'는 앱이 설명해야 하고,
  네이티브가 옆에서 도와줄 때 앱 설명만 보고 같이 진행할 수 있어야 한다."

## 구현

### Part A. 시나리오 화면에 buddyCard 노출
- Roleplay 시나리오 상세(연습 시작 전 소개 영역)에 접이식 카드
  **"👥 With a Korean friend? · 친구와 함께"**:
  - 학습자용 영어 1줄: "Hand the phone to your friend — the Korean note below tells them their role."
  - `instructionKo` 전문(큰 글씨 — 친구가 바로 읽는 용도) + `reactionKo`("친구가 이렇게 반응해 줄 수 있어요").
  - 기본 접힘(혼자 할 때 방해 금지).
- buddyCard가 없는 시나리오(있다면) 방어 렌더. lint-content에 buddyCard 필수 검사 이미 있는지 확인, 없으면 추가.

### Part B. 주간 버디 미션 카드 (Speak 탭)
- Speak 탭에 섹션 **"Buddy session · 이번 주 친구와"**:
  - 이번 주 추천 시나리오 3개 — 결정론적 선택: `현재 챕터 ±3 범위의 linked 시나리오 우선, 부족하면
    미완료(spokenProgress 기준) 시나리오에서 ISO 주차 시드로 회전`(같은 주엔 항상 같은 3개 — 친구와 약속해두고
    와도 그대로 있게. Date 사용은 컴포넌트 레벨 OK).
  - 각 항목: 제목 + 상황 1줄 + "함께 하는 법" 3단계 고정 안내(① 혼자 먼저 1회 → ② 친구에게 instructionKo 보여주고
    실제로 대화 → ③ 막힌 문장은 그 자리에서 why-natural 설명 같이 읽기).
  - 완료 체크는 기존 `spokenProgress` 재사용(신규 키 없이) — 시나리오 완료 시 미션도 채워진 것으로 표시.
- C13 완료 상태면 추천 3개는 register 필터(해요체 기본)를 따른다.

### Part C. Guide 매뉴얼 갱신
- "How to use this app"에 버디 세션 항목 추가: 주 2회 흐름, 친구에게 기대할 것/기대하지 말 것
  ("문법 설명은 앱이 합니다 — 친구는 발음과 '이 말 실제로 써?'만 봐주면 충분").

## 수용 기준
1. 시나리오 상세에서 buddyCard 렌더(접힘 기본, 펼침 시 한국어 안내 큰 글씨) — 브라우저 확인.
2. Speak의 주간 미션: 같은 주 재방문 시 동일 3개 유지·다음 주 회전(주차 mock 테스트), 완료 반영.
3. buddyCard 부재 방어 + 데이터 검사. 4. 테스트 green + build + lint:content. 5. 모바일 375px 레이아웃.

## 하지 말 것
- 친구용 별도 앱/모드 신설(카드 하나로 충분 — 과설계 금지). 신규 localStorage 키(기존 spokenProgress 재사용).
- buddyCard 내용 대량 재작성(C13의 해요체 변형분만 새로 쓰고 기존은 유지).
