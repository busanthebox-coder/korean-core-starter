# C12 — 구어 축약 노트

규모: 소. 의존 없음. 목표 한 줄: 교재 표기와 실제 말/카톡 표기의 간극(나는→난, 것이→게)을 한 화면으로 해소한다 —
존댓말에서도 그대로 쓰는 축약이라 반말 후순위 결정과 무관.

## 실측 근거
- 구어 축약을 가르치는 노트·화면 없음. Roleplay 실문장에는 이미 축약이 등장(안 와, 거 같아 등) —
  학습자는 배운 적 없는 표기를 만나는 중.

## 구현

### Part A. 문법 노트 1개 (textbook 스키마)
- 위치: **chapter-05**(Daily Actions — 조사·현재형을 막 배운 직후가 적기. 실행자가 grammarNotes 흐름 보고
  chapter-03과 비교 판단, 근거 기록).
- 제목: `구어 축약 — How Korean actually sounds` / 내용 확정:
  | 원형 | 축약 | 예 |
  |---|---|---|
  | 나는/저는 | 난/전 | 전 학생이에요 |
  | 너는 | 넌 | (읽기용) |
  | 것이/것을/것은 | 게/걸/건 | 먹을 게 없어요 |
  | 무엇을/무엇이 | 뭘/뭐가 | 뭘 먹을까요? |
  | 것 같아요 | 거 같아요 | 좋은 거 같아요 |
  | 이것/그것/저것 | 이거/그거/저거 | 이거 주세요 |
  | -지요 | -죠 | 맛있죠? |
- keyPoint: "표기는 줄어도 뜻·높임은 동일 — 쓰기 시험이 아니면 축약이 더 자연스럽다."
  pitfall: 영어권 학습자가 축약을 '비격식/반말'로 오해 — 거 같아요·전·이거는 존댓말에서도 표준.
- drill: 원형→축약 변환 4문항(기존 drill 스키마).
- 편집 후 `build-app-data`(rich-chapters 병합) — 노트 수 before/after 카운트.

### Part B. 채점 관용 (좁게)

### 배치: chapter-05 확정 (스펙이 요구한 3과 비교 판단, 근거)
축약표의 `난/전`은 **3과의 은/는**을, `게/걸/건`·`뭘`은 **5과의 을/를**을 이미 배웠어야 이해된다.
3과에 두면 표의 절반이 미배운 조사에 기대게 되므로 5과가 맞다(5과 노트 2 → 3, `Grammar 3/3`으로 렌더).

> 제목 변경(2026-07-21): `구어 축약` → **`자연스럽게 말하기`**. 사용자 요청 — "축약"은 문법 용어라
> 초보에게 무엇을 얻는지 알려주지 않는다. 영어 부제(How Korean actually sounds)는 유지.

### Part A — 문법 노트 1개 (`scripts/rich-chapters/chapter-05.json` grammarNotes[2])
`구어 축약 — How Korean actually sounds`. 스펙의 7행 표 확정안 그대로 + formTable/examples/keyPoint/
pronunciation/drill/englishSpeakerPitfall(형제 노트 스키마·키 순서 동일).

**교차 리뷰가 이 노트의 대들보를 무너뜨렸다 — 18건 지적(high 2 / medium 8 / low 8), 전부 반영:**
- **[high] 중심 주장이 반만 맞았다.** 내가 쓴 keyPoint "축약은 공손함을 안 바꾼다 — 반말은 -요를 빼는 것이지
  축약이 아니다"는 **공손함(politeness)은 맞고 격식(formality)은 틀리다**. `거 같아요`·`전`은 면접·자기소개서·
  업무 메일에서 실제로 부적절하다. → label을 "Shorter spelling, same politeness — **but not the same formality**"로
  바꾸고, `것 같아요`행에 `(speech only)` + "이메일·보고서엔 좋은 것 같습니다로 쓰라"는 반대 예시를 붙였다.
- **[high] 자기모순**: "-요만 붙으면 반말이 아니다"는 내가 같은 표에 넣은 `넌`행과 정면 충돌(`넌 밥 먹어요`는
  -요가 있어도 반말 — 너 자체가 반말 어휘). → 규칙 재작성.
- **[high] pronunciation 필드가 한국어 문어체로 작성됨**(A1 영어권 앱에서 학습자가 못 읽음. 형제 노트는 전부 영어) +
  **음운 주장이 사실과 다름**: 것을은 [거슬]이지 [거를]이 아니다 — 걸은 `것을`의 발음이 아니라 `거+를`의 융합.
  → 영어로 재작성 + 실제 경로(것→거 → 거+를→걸) 명시.
- **[medium] `무엇이 → 뭐가`는 축약이 아니다**: 무엇→뭐(어휘 축소) 후 **조사 이형태 교체**(뭐는 받침이 없어 가).
  융합이 아니므로 축약 기제로 가르치면 거짓. → 표에 경로를 명시.
- 그 외: `넌` 행에 `read only` 표기를 학습자가 스캔하는 `when` 칼럼으로 이동(ex에 묻혀 있었음),
  drill.model이 4문항 중 2패턴만 시범(형제 노트는 전부 시범) → 재작성, drill 2번의 정답이 같은 노트에
  2번 인쇄돼 있어 문제가 안 됨 → `이것 주세요` → `그것 좀 주세요`로 교체, `춥죠` 로마자 `chupjyo` → `chupjo`
  (ㅈ는 구개음이라 /jo/·/jyo/ 대립 없음 — 가져=gajeo 전례).
- 리뷰가 **통과시킨 것**도 기록: 것이→게/것을→걸/것은→건은 표준국어대사전과 일치, `춥죠`는 ㅂ불규칙 함정을
  올바르게 피함(-죠는 자음 어미), 예문 4개 전부 자연스러운 해요체, 반말 유출 0.

**리뷰 적용 후 발생한 레이아웃 회귀를 브라우저에서 잡아 수정**: 리뷰의 긴 설명문을 `add` 칼럼(축약형만 들어가는
짧은 강조 라벨)에 그대로 넣었더니 375px에서 "무엇을"이 **한 글자씩 세로로 쪼개짐**. 내용은 유지하고 산문을
전폭 `ex` 줄로 이동. 리뷰 텍스트를 필드에 기계 적용할 때 **칼럼 폭을 확인해야 한다**는 교훈.
