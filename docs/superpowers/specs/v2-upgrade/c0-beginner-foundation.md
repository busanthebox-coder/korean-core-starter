# C0 — 기초(A1/A2) 어휘·표현 기반 정비 ★콘텐츠 트랙 최우선

콘텐츠 트랙 **0순위**(다른 C보다 먼저 — 레벨 라벨은 배치테스트·사전 필터·B1 승격·C-시리즈 전체가 딛는 기반).
규모: 중. 의존: 재태깅을 시드에 반영하려면 WS2 이후가 안전(전이면 korean/data 직접 패치 방식 — WS2 전례).
목표 한 줄: 기초 학습자에게 "무엇을 먼저 배울지"가 데이터와 UI 양쪽에서 올바르게 보이게 만든다.

## 감사 결과 (2026-07-05 실측 — 이 스펙의 존재 이유)

**질문: 기초 레벨이 배우기에 충분한 내용이 잘 정리되어 있는가?**
**답: 내용은 충분하다(98%+). 정리(라벨·연결)가 고장나 있다.**

### ✅ 충분성 — 문제 없음
- 표준 A1 필수 체크리스트 175개(숫자·요일·가족·대명사·음식·장소·사물·색·몸·기초 형용사/동사·나라/직업)
  대비 **172개 존재(98%)**. 부재 3개도 사실상 대체 존재: 있다/없다→있어요/없어요(표현), 까만색→검은색.
- 총량: A1 라벨 1,368 + A2 라벨 2,247 항목. 표현 788개(인사·식당·쇼핑·교통 등 상황별 완비).

### ❌ 문제 1 — 레벨 라벨이 교육 실체와 어긋남 (핵심 결함)
- **필수 초급어 129/175(74%)가 A2로 오태깅**: 하나·둘·셋, 월요일~일요일, 엄마·아빠·언니·오빠,
  저·나·여기·저기, 밥·김치·빵, 빨간색, 머리·눈·손, 덥다·춥다·아프다, 한국·미국… 전부 A2 라벨.
- 원인: 생성기(generate-korean-data.mjs 1060행대)가 extendedVocab에 **기본값 `level: 'A2'`** 를 박음
  (`entry.level = o.level || 'A2'` — 시드 대부분 level 미지정).
- 역방향 오류도 존재: words 섹션은 사실상 전부 A1 라벨(당황하다·토하다·작성하다 같은 B급 동사 포함).
  결과: A1 라벨 단어의 품사 분포가 **동사 497 / 명사 55 / 형용사 8** — 초급 사전 필터가 앞뒤로 다 틀림.
- 파급: Dictionary 레벨 필터, WS4 배치테스트 문항/추천, data.js의 B1 승격 로직, C4/C6 레벨 필터 전부 오염.

### ❌ 문제 2 — 필수 어휘가 코스 동선 밖에 떠 있음
- A1 챕터(1~11과)가 연결한 고유 entry는 **193개뿐**(챕터당 15~32 + 내장 richVocab 16~20 — 과당 분량은 적정).
- 필수어 표본 22개 중 **9개(41%)는 어느 챕터에도 연결 안 됨**: 화요일·엄마·아빠·빨간색·눈·침대·창문·우유·계란.
  → 요일·가족·색·몸·집안 사물 같은 "주제 어휘 세트"가 사전에만 존재, 코스를 따라가는 학습자는 만날 길이 없다.
  (숫자는 15과에서 다루나 그건 A2 트랙 — 세종학당·교과서는 숫자·요일을 첫 몇 주에 가르친다.)

## 구현 — 3파트

### Part A. 레벨 재태깅 (데이터 정합)
1. **표준 체크리스트 확정**: 이 감사의 175개를 시작으로 세종학당 초급 어휘 범주를 반영해
   `scripts/level-audit/a1-checklist.json`으로 체크인(~250개 목표: 위 13범주 + 날씨·교통·의문사 보강).
2. **하향 재태깅(A2→A1)**: 체크리스트 매칭 항목을 A1으로. 시드에 `level:'A1'` 명시가 정석(WS2 후) —
   WS2 전이면 korean/data 직접 패치 + 시드에도 동일 반영(이중 기록)으로 재생성 안전 확보.
3. **상향 재태깅(A1→A2/B1)**: words 섹션 동사 497개를 에이전트 배치 리뷰로 3단 분류(A1 핵심동사 ~80 /
   A2 / B1 후보). 판정 기준: 세종학당 초급 목록·TOPIK I 여부·일상 빈도. 결과를 `level-audit/verb-levels.json`에
   기록하고 적용. (당황하다·작성하다·서명하다 = A1 아님이 명백한 사례.)
4. **생성기 수정**: extendedVocab 기본값 `'A2'` 의존을 끊고 **시드에 level 필수화**(누락 시 generate가 경고 목록 출력).
5. 회귀 가드: `src/lib/data.test.js`에 "체크리스트 표본 30개는 level==='A1'" 스냅샷 테스트.

### Part B. 주제 어휘 팩 (Vocab Packs — 코스 동선에 편입)
챕터 문법 서사를 건드리지 않고 어휘 세트를 배울 **미니 학습 단위** 신설:
1. 데이터 `scripts/vocab-packs.json` (체크인, build로 병합):
   ```json
   {"id":"pack-numbers","title":"Numbers 1–10 & Sino","icon":"ti-123","level":"A1",
    "afterChapterNumber":3, "entryHangul":["하나","둘",...], "tip":"고유수 vs 한자수 한 줄 규칙"}
   ```
   **팩 8개(v1)**: 숫자(고유+한자 기초) / 요일·때 / 가족 / 색 / 몸 / 음식 기초 / 집·사물 / 나라·직업.
   entryHangul→entryId 해석은 빌드 타임(미해석 항목은 빌드 에러 — 오타 방지).
2. UI: Learn 챕터 목록에서 `afterChapterNumber` 위치에 팩 카드(챕터 카드보다 작게, "Vocab Pack" 배지).
   열면 **LessonPlayer의 Words 화면 재사용**(6개씩 청크) + 마지막에 matchGame 1판(MatchGame.svelte 재사용).
   완료는 `kcs.packs-v1`(Set) — WS3 BACKUP_KEYS·00-README 표에 추가.
3. 팩 완료 어휘는 (WS5 존재 시) SRS 후보로 노출("이 팩을 복습 덱에 추가" 버튼 — 자동 등록은 안 함).
4. 잠금 없음(챕터와 동일 원칙). 진행률 카운트에 팩 포함 여부는 별도 표기(챕터 65 + 팩 8 혼동 방지).

### Part C. 부재·대체 어휘 마감
- `까만색`: 검은색이 있으므로 **추가하되 검은색 항목에 유의어로 연결**(둘 다 고빈도 — 사전에 아예 없는 건 부자연).
- `있다/없다`: 사전형 headword 추가 여부는 **하지 않는다**로 결정 — 앱 전반이 해요체 우선이고
  있어요/없어요 표현이 이미 깊게 다뤄짐(4과). 대신 4과 grammarNote에 사전형 언급이 있는지 확인만.
- 색 이름 세트 점검: 빨간·파란·노란·하얀·검은 + 초록색·갈색·회색·보라색·분홍색·주황색까지 팩에 필요한
  항목이 사전에 있는지 확인, 없는 것만 시드 추가(WS2 규칙 준수).

## 검증·수용 기준
1. 재감사 스크립트(이 감사와 동일 로직을 `scripts/level-audit/audit-a1.mjs`로 체크인) 재실행 →
   체크리스트 **A1 라벨 커버리지 ≥95%**(현 26%), A1 단어 품사 분포가 명사·형용사 포함 균형으로 개선 리포트.
2. 필수어 표본의 챕터/팩 도달률: "어느 챕터·팩에서도 못 만나는 필수어" **0개**.
3. 팩 8개 렌더·완료 E2E 1회(프리뷰). matchGame 동작. 4. Dictionary A1 필터에 엄마·하나·월요일이 보인다.
5. 전 테스트 green + build. WS2 완료 상태면 generate 재실행에도 재태깅 유지(시드 반영 증명).
