# C7 — 한자어 어근 패밀리 (Sino-Korean Word Networks)

콘텐츠 트랙. 규모: 중. 의존 없음. 오디오 무관.
목표 한 줄: "학(學)을 알면 학교·학생·학원·방학·유학이 한 번에 풀린다" — 어근 40개로 B1+ 어휘 확장 엔진을 만든다.

## 교육적 근거
한국어 어휘의 절반 이상이 한자어. 어근 인식은 모르는 단어의 뜻을 추론하게 하는 최고의 어휘 전략인데,
현재 앱에는 collocations만 있고 어근 네트워크가 없다. 한자 **쓰기**를 가르치는 게 아니라
**소리·뜻 단위 인식**만 가르친다(한자 자형 학습은 범위 밖 — 부담 최소화).

## 데이터 설계: `scripts/hanja-src/roots.json`

```json
{
  "id": "root-hak", "hanja": "學", "reading": "학", "gloss": "배우다 · learning",
  "note": "Words with 학 are about learning and study.",
  "members": [
    {"entryId": "word-...", "hangul": "학교", "breakdown": "학(learn)+교(school building)"},
    {"entryId": "word-...", "hangul": "학생", "breakdown": "학(learn)+생(person/life)"}
  ],
  "level": "A2"   // 이 어근 카드를 노출할 최소 레벨
}
```

### 어근 40개 목표 목록 (reading 기준 — 사전 매칭으로 members 확정)
생활 빈도 최상위. **동음이의 한자 함정 주의**(같은 소리 '사'가 事·社·士·四로 갈라짐 — 어근은 한자 단위,
매칭은 사람이 아닌 리뷰 에이전트가 단어별로 breakdown을 검증):

| 그룹 | 어근(한자·뜻) |
|---|---|
| 배움 | 학學 배움 · 교敎 가르침 · 생生 삶/사람 · 원院 기관 · 실室 방 |
| 시간 | 일日 날 · 월月 달 · 년年 해 · 시時 때 · 간間 사이 · 주週 주 |
| 사람·사회 | 인人 사람 · 자者 사람 · 가家 집/전문가 · 회會 모임 · 사社 회사 · 국國 나라 · 민民 백성 |
| 공간 | 장場 장소 · 소所 곳 · 상上 위 · 하下 아래 · 중中 가운데 · 내內 안 · 외外 밖 |
| 생활 | 식食 먹다 · 물物 물건 · 차車 차 · 전電 전기 · 화話 말 · 문門 문 |
| 행위 | 동動 움직임 · 행行 가다/하다 · 작作 만들다 · 용用 쓰다 · 발發 일어나다 |
| 상태·정도 | 대大 크다 · 소小 작다 · 신新 새롭다 · 다多 많다 |

(40개 채우되, 사전 내 파생어 **3개 미만**인 어근은 교체 — members가 빈약하면 교육 효과가 없다.)

## 구축 파이프라인 (자동 추출 + 에이전트 검증 — 오매칭이 최대 리스크)

1. **후보 자동 추출** `scripts/extract-hanja-candidates.mjs`:
   사전 전 항목(headword)에서 각 reading 음절을 포함하는 단어를 긁어 후보 목록 생성.
   당연히 쓰레기가 섞인다(예: '사과'의 '사'는 한자 어근 아님, '학'이 든 고유어 등).
2. **교차 검증(핵심 단계)**: 리뷰 에이전트가 후보 각각에 대해 (a) 실제 그 한자인가
   (b) breakdown이 정확한가 (c) 학습 가치(빈도) 판정 → 확정 members만 남김.
   **동음이의 분리**: '문門(문)'과 '문文(글)'처럼 소리가 같으면 어근 카드를 분리하고 members를 나눈다.
3. 확정본을 roots.json으로 저장 → build-app-data 병합(작음, core에 포함) → 검증 스크립트:
   entryId 실존·중복 멤버·어근당 members ≥3.

## UI

1. **EntryDetail 연동**(가장 중요한 노출): 한자어 항목 상세에 "같은 어근" 접이식 섹션 —
   "학(學 learning): 학교 · 학생 · 방학 · 유학" 각 단어 탭하면 해당 EntryDetail로.
   역인덱스(entryId → rootIds)를 로드 시 1회 구축.
2. **어근 브라우저**: Dictionary 탭에 "Roots" 서브 뷰(또는 Guide 카드) — 어근 카드 그리드(한자·소리·뜻·단어 수),
   카드 열면 members 목록 + breakdown.
3. **미니 퀴즈**: 어근 카드 하단 "이 어근이 든 단어는?" 3문항(members에서 정답, 다른 어근 members에서 오답 자동 생성 —
   코드 생성이라 콘텐츠 작업 없음). 오답 → mistakes/SRS(WS5 시).
4. 레벨 게이트: entry.level 기준 A1 사용자에게도 보이되, 어근 브라우저 정렬은 level 순.

## 테스트·수용 기준
1. 40어근·전 어근 members ≥3·entryId 전부 실존(검증 스크립트 통과).
2. 동음이의 분리 사례 ≥2건이 리포트에 기록(문·사 등에서 반드시 나온다 — 없으면 검증이 안 돌았다는 뜻).
3. EntryDetail "같은 어근" 렌더 + 상호 이동 E2E 1회. 미니 퀴즈 오답 자동 생성 로직 테스트.
4. 전 테스트 green + build.

## 하지 말 것
- 한자 자형·획순 교육(범위 밖). 어근 어원 장문 해설(카드 note 1~2문장이면 충분).
- 자동 추출 결과를 검증 없이 출시(오매칭 = 잘못된 어원 지식을 가르치는 최악의 결과).
