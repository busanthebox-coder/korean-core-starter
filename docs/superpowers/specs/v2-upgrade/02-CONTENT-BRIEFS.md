# 콘텐츠 브리프 — 무엇으로 채울지의 실제 청사진

> 지시서(01)가 "어떻게 돌릴지"라면, 이 문서는 **무엇을 만들지의 실물 목록·초안·예시**다.
> 실행자는 해당 지시의 생성 스펙을 쓸 때 이 브리프의 절을 그대로 기초로 삼는다(재발명 금지).
> 여기 실린 한국어 초안도 반드시 교차 리뷰를 거친다 — 설계자(Fable) 초안도 예외 없음.

## B1 — C0 어휘 팩 8개: 실제 수록 목록

규칙: 각 항목은 사전에 실존해야 함(빌드 타임 검증). 없으면 (a)유의 표제어로 대체하거나 (b)시드 추가(WS2 규칙).
팩당 12~20개, 학습 순서대로 나열(쉬운 것→덩어리 규칙).

**pack-numbers (3과 뒤)** — 하나 둘 셋 넷 다섯 여섯 일곱 여덟 아홉 열 / 일 이 삼 사 오 육 칠 팔 구 십 백 천 만
· tip: "개수·나이·시각(시)=고유수, 날짜·돈·분·전화번호=한자수"
**pack-time (5과 뒤)** — 오늘 어제 내일 지금 아침 점심 저녁 밤 주말 월요일 화요일 수요일 목요일 금요일 토요일 일요일 시간 분
· tip: "요일은 전부 -요일; に해당하는 조사는 6과에서"
**pack-family (2과 뒤)** — 가족 엄마 아빠 어머니 아버지 언니 오빠 누나 형 동생 할머니 할아버지 아들 딸
· tip: "언니/오빠는 여자가, 누나/형은 남자가 부르는 손위 호칭"
**pack-colors (16과(Descriptions) 앞·뒤 아무 데나 A2 초입)** — 빨간색 파란색 노란색 초록색 검은색(유의: 까만색) 하얀색 갈색 회색 분홍색 보라색 주황색 색깔
· tip: "색+이에요 / 빨간+명사 두 용법"
**pack-body (3과 뒤 또는 A2 초입)** — 몸 머리 얼굴 눈 코 입 귀 목 어깨 팔 손 손가락 배 다리 무릎 발
· tip: "아프다와 짝: 머리가 아파요"
**pack-food-basic (7과 뒤)** — 밥 물 김치 고기 생선 야채 과일 빵 우유 계란 커피 차 맥주 소주 음식 음료수
· tip: "N 주세요/N 먹어요 프레임에 바로 끼우기"
**pack-home-things (6과 뒤)** — 집 방 문 창문 책상 의자 침대 옷 신발 가방 책 펜 휴대폰 컴퓨터 우산 돈
· tip: "있어요/없어요·어디에 있어요? 프레임 재활용"
**pack-people-places (4과 뒤)** — 한국 미국 중국 일본 사람 친구 학생 선생님 의사 회사원 학교 회사 병원 식당 카페 화장실
· tip: "저는 N이에요 + N에 가요 두 프레임"

리뷰 중점: 목록-사전 매칭률 100%, 팩 위치(afterChapterNumber)가 그 프레임을 이미 배운 뒤인지.

## B2 — WS8 문법 갭필 3건: 노트 내용 초안 (스키마에 맞춰 완성할 것)

### ① -지요/죠 (확인·동의 구하기) → chapter-35 권장
- func 초안: "화자가 이미 안다고 생각하는 것을 상대에게 확인하거나 동의를 구할 때. 억양은 내려간다.
  질문(-아요?)이 정보를 구한다면, -지요?는 '그렇지?'라고 맞장구를 청한다."
- formTable: V/A + 지요(→죠 축약) / N + (이)지요 — 받침 무관 동일.
- 예문 상황 4: ①날씨 맞장구(오늘 덥죠?) ②사실 확인(민수 씨는 학생이지요?) ③당연함(한국어는 재미있죠)
  ④부드러운 자기 확인(내일 시험이죠? 맞죠?)
- keyPoint: "-아요? = 몰라서 묻기 / -지요? = 알면서 확인하기"
- pitfall: 영어 화자는 tag question(isn't it?)을 -아요?로 직역 → 심문처럼 들림. -죠가 자연.

### ② 반말 세트 (평서·의문·명령·청유) → chapter-33 증설
- func 초안: "해요체에서 요만 떼면 반말 평서·의문이 된다(먹어요→먹어). 명령도 동일(앉아),
  청유는 -자(가자). 이름 부르기는 N+아/야."
- formTable: 평서/의문 -아/어 · 명령 -아/어 · 청유 -자 · 호격 아(받침O)/야(받침X).
- 예문 상황 4: 친구 사이 일상(밥 먹었어? / 같이 가자 / 이리 와 / 지민아, 뭐 해?)
- keyPoint: "요-떼기 규칙 + 존댓말→반말 전환은 상대가 허락한 뒤(말 놔도 돼요?)"
- pitfall: 반말=무례가 아니라 친밀 신호. 단 손윗사람·초면에 쓰면 큰 실례 — 전환 타이밍이 문법보다 중요.

### ③ -(으)ㅂ시다 (격식 청유) → chapter-24, -(으)ㄹ까요?와 대비
- func 초안: "함께 하자고 격식 있게 제안. 회의·안내방송·연설 톤. 친구 사이엔 -자, 부드럽게는 -(으)ㄹ까요?"
- formTable: 받침O+읍시다(먹읍시다)/받침X+ㅂ시다(갑시다).
- 예문 상황 4: 회의(시작합시다), 안내(다음 역에서 내립시다→공지 톤), 건배(건배합시다), 캠페인(지킵시다).
- keyPoint: 3층위 사다리 — 가자(반말) < 갈까요?(부드러운 제안) < 갑시다(격식·단체).
- pitfall: 손윗사람 1:1에게 -(으)ㅂ시다는 실례가 될 수 있음(지시처럼 들림) → -(으)시겠어요?가 안전.

## B3 — C2 신규 문항: 유형별 실물 예시 + 오답 설계 규칙

### 실물 예시 (이 품질·형식 그대로)
```json
{"type":"particleChoice","prompt":"주말에 친구___ 영화를 봤어요. (with a friend)","options":["하고","를","에"],
 "correct":"하고","explanation":"'with'는 하고. 를은 목적어(영화를), 에는 시간·장소(주말에)에 이미 쓰였다.","entryIds":[]}

{"type":"conjugate","prompt":"어제 도서관에서 책을 ___ . (읽다 → past)","base":"읽다","form":"past",
 "correct":"읽었어요","explanation":"읽다: 받침 있고 모음이 ㅣ 계열 → -었어요. 어제가 있으니 과거."}

{"type":"orderWords","prompt":"I drank coffee at a cafe this morning.",
 "tokens":["오늘 아침에","카페에서","커피를","마셨어요"],"correct":"오늘 아침에 카페에서 커피를 마셨어요",
 "explanation":"시간 → 장소 → 목적어 → 동사. 한국어 기본 어순: 언제-어디서-무엇을-했다."}
```

### 오답(보기) 설계 규칙 — 유형별 실제 학습자 오류에서
| 대상 | 좋은 오답(진짜 헷갈림) | 금지 오답(아무 말) |
|---|---|---|
| 조사 | 은↔이(주제/주어), 에↔에서, 을↔이, 도↔만 | 전혀 무관한 조사(께서를 A1에) |
| 활용 | 받침 규칙 위반형(먹어요→먹아요), 불규칙 미적용(듣어요), 시제 혼동(먹어요/먹었어요) | 존재하지 않는 어미 |
| 문형 | 형태 유사 문법(-(으)러/-(으)려고), 어순 뒤집기 | 다른 품사 난입 |
- explanation은 항상 2문장 구조: "왜 정답인가" + "가장 유혹적인 오답이 왜 틀렸나".
- 어휘 통제: 그 챕터+선행 챕터 어휘만. 리뷰어는 후행 챕터 문법이 문항에 섞였는지 표시 번호로 검사.

## B4 — C4 대조 뱅크: 완성 예시 1쌍 + 저작 규칙

### 완성 예시 — "안 vs 못" (A1) 6문항의 골격
정답 분포 3:3, 상황이 판별 축(의지 vs 능력·외부 사정)을 정확히 가르도록:
1. 다이어트라서 야식을 __ 먹어요 → 안 (스스로 선택)
2. 이가 아파서 사과를 __ 먹어요 → 못 (능력 불가)
3. 오늘은 바빠서 운동을 __ 했어요 → 못 (사정)
4. 저는 술을 __ 마셔요. 싫어해서요 → 안 (기호)
5. 표가 없어서 콘서트에 __ 가요 → 못
6. 피곤해서 오늘은 요리를 __ 하고 시켜 먹을래요 → 안 (선택)
- explanation 형식: "이 문장은 [의지/외부 사정] 상황 → __. 반대쪽이면 뉘앙스가 [어떻게] 달라진다."

### 나머지 29쌍 저작 규칙
- c4-contrast-bank.md 표의 "판별 규칙 씨앗"을 6문항이 **각기 다른 상황**으로 분산 구현(같은 동사 반복 금지).
- 함정쌍(#23 -(으)ㄹ 뻔했다/뿐이다)은 형태 구별 2문항 + 의미 구별 4문항 배합.
- 존대 관련(#22)은 대상(친구/할머니/사장님)이 판별 축 — 어휘로 답이 새지 않게 주의.

## B7 — WS4 배치 문항 선별 기준 (뱅크 큐레이션 가이드)

- 레벨당 5~8문항. **판별력 우선순위**: A1 = 이에요/예요 받침, 은/는 vs 이/가, 을/를, 있어요/없어요 /
  A2 = 과거 -았/었, -(으)ㄹ 거예요, -아서 vs -니까, 세 시 vs 삼 시(수사) /
  B1 = -다고 하다, -는 것 같다 vs -나 보다, 께서+-시-, -(으)ㄹ 수밖에.
- 어휘 난도로 판별되는 문항 금지(문법만 가려야 함) — 보기·지문 어휘는 전부 A1 수준으로.
- 같은 문법을 두 번 묻지 않는다(문항 수가 적으므로 커버리지 우선).

## B8 — C9 Day-1 온램프: 확정 내용물

### B8-1. "How Korean Works" 오리엔테이션 10개 개념 카드 (순서 고정)
1. **한글은 알파벳이다** — 문자가 곧 소리. 그림이 아니라 24자 조합 · 예: ㅎ+ㅏ+ㄴ=한 · → 1과
2. **동사가 문장 끝에 온다** — "I pizza eat" 순서 · 예: 저는 피자를 먹어요 · → 5과
3. **조사가 역할을 표시한다** — 영어가 어순으로 하는 일을 작은 꼬리표가 한다 · 예: 은/는·을/를 · → 3·5과
4. **동사는 주어 따라 안 변한다** — I/you/he 전부 같은 형태. 대신 시제·공손함으로 변한다 · 예: 먹어요 · → 5과
5. **높임은 같은 말의 다른 옷** — 해요체 하나면 어디서든 예의 바르다(이 앱의 기본) · 예: 감사합니다/고마워 · → 40과
6. **관사·복수 걱정 없음** — a/the/-s가 없다 · 예: 사과 = an apple/apples · → 3과
7. **질문은 억양만 올리면 된다** — 어순 도치 없음 · 예: 학생이에요 ↘ / 학생이에요? ↗ · → 3과
8. **주어는 자주 생략된다** — 맥락이 말해준다 · 예: (저는) 괜찮아요 · → 2과
9. **숫자가 두 벌이다** — 세는 것(고유)·날짜/돈(한자) · 예: 세 시 삼십 분 · → 15과
10. **글자와 소리가 살짝 다르다** — 연음 때문. 규칙은 나중에, 지금은 놀라지만 말 것 · 예: 한국어→[한구거] · → 31과
· 카드 형식: 개념 헤드라인(영) + 2문장 설명(영) + 한국어 예 1개(로마자 병기) + "Learn this in Chapter N" 링크.

### B8-2. 생존 표현 팩 2개 수록 목록

### B8-3. 키보드(IME) 가이드 아웃라인 — Guide 유닛 "Set up Korean typing"
1. 왜 필요한가 2문장(이 앱의 타이핑 연습 + 실생활 검색/문자).
2. 플랫폼별 3~5단계: iOS(설정→일반→키보드→한국어, 지구본 전환) / Android(Gboard→언어→한국어 2-set) /

3. 두벌식 30초: 자음 왼손·모음 오른손, 받침은 그냥 이어 치면 자동 조합(ㅎ+ㅏ+ㄴ→한).

## 공통 리뷰 체크리스트 (모든 브리프의 교차 리뷰에서 기계적으로 적용)

1. 문법: 활용·조사·받침 규칙 정오(불규칙 최우선 검사).
2. 자연스러움: 원어민이 실제로 말하는가(번역투·교재체 탈락).
3. 어휘 통제: 고빈도 + 해당 레벨/챕터 범위. '명함류' 저빈도어 발견 즉시 교체.
4. 정답 유일성(객관식): 한국어 특성상 복수 정답 위험 — 보기마다 "이게 왜 안 되는지" 답할 수 있어야 통과.
5. 로마자·영역: 형식 일치, 오역 없음.
6. 스키마: 필수 필드·타입 정확(기계 검증과 이중).
