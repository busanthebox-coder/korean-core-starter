# V3 — Conversation-First: 단순하게, 말하게, 친구와 함께

> 설계: Fable (2026-07-10). 실행: Opus/Codex — 이 파일 하나로 자기완결(부록에 실행 지시 포함).
> V2(기능·콘텐츠 완비)의 다음 단계. V2 규칙( [v2-upgrade/00-README.md](v2-upgrade/00-README.md) 공통 규칙,
> generate 금지 해제됨 — WS2 완료, preflight 필수, 커밋은 요청 시만)을 그대로 상속한다.

## 1. 제품 재정의 (사용자 확정, 2026-07-10)

**대상**: 영어권 원어민. **혼자서**, 또는 **옆에 앉은 한국인 친구와 함께** 공부한다.
**북극성**: "이 앱으로 공부하면 나중에 한국어로 **대화**할 수 있다." — 모든 화면·기능은
"이게 학습자를 말하기에 가깝게 하는가?"로 정당화된다. 못 하면 강등(삭제 아님 — 라이브러리로).

V2가 만든 것: 교과서(문법·읽기·쓰기·드릴)로서는 완성형. V2가 만들지 못한 것: **말하는 사람**.
Shadow(따라 말하기)·Roleplay(스크립트 선택)는 있지만 회화로 가는 "설계된 길"이 없고,
기능이 늘며 원래 문제("어려워 보인다")가 되돌아왔다.

## 2. 진단 — 복잡함의 실측 (2026-07-10)

| 표면 | 실측 | 문제 |
|---|---|---|
| 탭 | 6개 (Learn/Practice/Shadow/Roleplay/Dictionary/Guide) | Shadow·Roleplay가 말하기를 두 조각으로 쪼갬 |
| Practice 모드 | **9개** (review/quiz/write/build/match/contrast/conjugation/listening/weak) | 초보에게 9지선다 — "뭘 눌러야 하죠?" |
| Learn 홈 | 4중 스택: LearnProgressCard + LearnMissionPanel + 레벨 그룹(챕터 65+팩 10+체크포인트 3) + ReadingRoom + 오리엔테이션 카드 | 첫 화면 의사결정 ~20개 |
| 학습자의 질문 | "지금 뭘 하면 되지?"의 답이 화면에 없다 | 안내는 Guide 문서에만 존재 |

원칙: **기능은 죄가 없다 — 배치가 죄다.** V3는 기능을 지우지 않고, "오늘의 한 줄 길" 뒤로 숨긴다.

## 3. 세 기둥

### 기둥 A — Simplify: "오늘" 한 줄 길 (선택지 20개 → 1개)
1. **Today 카드가 Learn 홈의 왕**: 첫 화면 = Today 카드 하나가 지배(상단 고정, 크게).
   내용: "오늘의 15분 — ① 복습 N개 ② 다음 레슨 이어서 ③ 소리 내어 말하기 1개" + 큰 버튼 **[Start]**.
   Start를 누르면 **자동 시퀀스**로 이어진다: due 복습(있으면) → 현재 챕터 다음 화면들 → Say-it(기둥 B) → 완료 도장.
   각 구간 사이 이동은 자동(모드 선택 화면 경유 금지). 중간 이탈 자유.
2. **Learn 홈 다이어트**: LearnProgressCard·LearnMissionPanel을 Today 카드 하나로 **통합**(중복 정보 제거).
   ReadingRoom·체크포인트·팩은 레벨 그룹 안 제자리 유지하되, 홈 최상단에서는 안 보이게(스크롤 아래).
   목표: **첫 뷰포트(모바일 375px)에 Today 카드 + 현재 레벨 그룹 헤더만.**
3. **Practice 스마트 런처**: 9개 모드 그리드를 "추천 1개 + 더보기"로. 추천 로직(순수 함수 `recommendDrill()`):
   due>0 → Review / 오답 많은 유형 → 해당 드릴 / 최근 챕터가 활용 챕터 → Conjugation / 기본 → Quiz.
   "더보기" 펼치면 기존 9개 전부(전문가 경로 보존).
4. **탭 6→5: Shadow + Roleplay → "Speak" 탭 통합**. Speak 안에서 두 모드(Listen & repeat / Respond)는
   유지하되 하나의 말하기 여정으로 배치(아래 기둥 B). 라우트 /talk·/chat은 리다이렉트로 보존(북마크 호환).

### 기둥 B — Speak-first: 회화로 가는 설계된 길
1. **Say-it 화면**(레슨 마지막, 쓰기 다음): 그 챕터 핵심 문장 3개를 **소리 내어** 말하는 화면.
   문장 = 대화의 내 차례 대사(extendedDialogue에서 자동 추출, 8~20자). 흐름: 문장 보기 → (TTS 가능하면 듣기) →
   가리고 말하기(탭하면 문장 숨김/표시) → "말했어요" 체크 3개. 녹음·채점 없음(마이크 권한 장벽 금지) —
   습관 형성이 목표. `kcs.spoken-v1`에 챕터별 기록.
2. **회화 마일스톤**: 체크포인트(A1/A2/B1) 옆에 "Conversation Milestone" 카드 —
   "이제 실제 사람과 이걸 해보세요" 시나리오 1개(부록 브리프 B-1에 3개 확정: A1 자기소개+주문,
   A2 주말 이야기+길 묻기, B1 경험담+의견). 구성: 미션 설명 + 예상 대화 흐름(내 차례만 힌트) +
   준비 체크(관련 챕터 링크) + **"실제로 해봤어요" 자가 체크**(날짜 기록, `kcs.milestones-v1`).
   앱이 대화를 시뮬레이션하는 게 아니라 **앱 밖 실전으로 내보내는 장치** — 친구(기둥 C)가 있으면 그 자리에서.
3. **Speak 탭 재구성**: 상단에 "오늘의 말하기"(현재 챕터 Say-it 문장 + Shadow 1개 + Roleplay 1개 추천),
   아래에 기존 라이브러리. 진행률은 챕터가 아니라 **"소리 내어 말한 날 수"**로 표시(회화 습관 지표).

### 기둥 C — Buddy Mode: 한국인 친구와 같은 화면으로 (차별화 핵심)
전제: **계정·네트워킹 없음** — 같은 기기를 사이에 두는 pass-and-play. 정적 사이트 유지.
전역 토글(Speak 탭 + 레슨 대화 화면에 "🤝 With a friend" 버튼, `kcs.buddy-v1` 기억). 켜면:
1. **대화 역할 나누기**(레슨 extendedDialogue + Shadow): 친구가 A역(한국어 원문+**친구용 한국어 안내**:
   "천천히, 두 번 읽어 주세요"), 학습자가 B역(첫 시도는 힌트 가림). 역할 교대 버튼. 턴별로 화면이
   "지금 읽는 사람"을 크게 표시.
2. **Roleplay 라이브 모드**: 스크립트 선택지 대신 친구가 상대역을 실제로 연기. 화면은 친구에게
   **상황 카드(한국어)** — "당신은 카페 직원입니다. 주문을 받고, 사이즈를 물어보세요" — 를,
   학습자에게 미션(영어)을 보여준다. 종료 후 친구가 3버튼 평가: 👍 통했어요 / 🔁 다시 / 💬 이 표현을 알려줬어요
   (마지막 선택 시 친구가 가르쳐준 표현을 메모로 입력 → 학습자 노트 `kcs.buddy-notes-v1`에 저장, 사전 검색 링크).
3. **친구 퀴즈**: 친구 화면에 정답+한국어 지시("이 단어를 한국어로 물어보세요"), 학습자는 입으로 답.
   친구가 O/X 탭 — 오답은 SRS 유입(기존 경로 재사용).
4. **친구용 UI 언어 원칙**: 친구에게 보이는 카드·지시문은 **한국어**(친구는 영어를 못 할 수도 있다),
   학습자 UI는 영어 유지. 이 원칙이 buddy 화면 설계의 리트머스다.

## 6. 수용 기준 (핵심만 — 상세는 부록 지시에)

3. Buddy 토글 시 대화 화면이 역할 분할로 전환되고, 친구용 텍스트가 전부 한국어다.
4. 마일스톤 "해봤어요" 체크가 기록·표시된다. 5. 전 테스트 green + preflight + 기존 라우트 리다이렉트 동작.

# 부록 2 — 콘텐츠 브리프

## B-1. 회화 마일스톤 3종 (확정)

**M-A1 "첫 대화" (A1 체크포인트 옆)** — 미션: 처음 만난 한국인에게 자기소개하고, 카페에서 주문까지.
대화 흐름 힌트: 인사 → 이름·직업 → 출신 → "만나서 반가워요" → (카페) 메뉴 주문 + 가격 묻기.
준비 체크: 2과(인사)·3과(이에요)·7과(주문)·pack-survival-basics. 성공 기준(자가): "상대가 내 말을 되묻지 않고 이해했다 1회 이상".

**M-A2 "주말 이야기" (A2 체크포인트 옆)** — 미션: 지난 주말에 뭐 했는지 말하고, 상대의 주말을 묻고,
다음에 같이 뭘 할지 제안하기. 흐름: 과거형 서사 2~3문장 → "주말에 뭐 했어요?" → -(으)ㄹ까요? 제안.
준비 체크: 12과(과거)·14과(의문사)·19과(제안)·M-A1 완료 권장. 성공 기준: "질문-대답이 3턴 이상 이어졌다".

**M-B1 "내 생각 말하기" (B1 체크포인트 옆)** — 미션: 최근 본 것(드라마·영화·장소) 경험담 + 이유 있는 의견 +
상대 의견에 반응하기. 흐름: -아/어 봤는데 → -는 것 같아요/-거든요 → "그렇죠?/왜요?" 반응.
준비 체크: 35과(의견)·43과(-더라고요)·49과(경험). 성공 기준: "내 의견에 상대가 실질적으로 응답했다".

카드 공통 형식: 미션(영어) / 흐름 힌트(한국어 문형 + 영어 주석) / 준비 체크리스트(링크) /
"해봤어요" 체크+날짜 / 응원 한 줄(부담 제거: "완벽할 필요 없어요 — 통하면 성공").

## B-2. Say-it 문장 선별 규칙
- 학습자(B역) 차례 대사 우선, 8~20자, 그 챕터 문법 포함 문장 우선순위 상향.
- 존대 기본(반말 챕터는 반말). 이름·고유명사가 든 문장은 치환 가능하면 일반형으로.
- 3문장 구성: 쉬움(짧은 정형구) 1 + 핵심 문법 1 + 질문형 1(대화는 질문으로 이어진다).

## B-3. 친구용 한국어 카드 문체 규칙
- 존댓말, 2~3문장, 명령이 아니라 부탁 톤("~해 주세요"). 학습자 수준 명시("초급이에요. 천천히요.").
- 전문용어 금지(문법 용어 대신 "과거로 물어봐 주세요" 같은 일상어).
- 각 카드 끝에 친구가 쓸 수 있는 리액션 예시 1개("오, 잘하는데요? / 한 번 더?").
