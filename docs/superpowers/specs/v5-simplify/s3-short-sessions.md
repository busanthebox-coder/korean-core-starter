# S3 — 짧은 세션: 레슨에 끝나는 지점 만들기

규모: 소~중. 의존: 없음.
목표 한 줄: "10 minutes for today"라고 약속했으면 10분에 끝나는 지점이 있어야 한다.

## 실측 근거 (2026-07-20)

**먼저, 홈 화면은 문제가 아니었다.** 화면별 선택지를 실측한 결과:

| 화면 | 기본 상태에서 사용자가 보는 것 |
|---|---|
| Learn | 주 액션 1개(Start now) + 레벨 그룹 1개. **한 화면에 다 들어감**(스크롤 없음) |
| Practice | 통계 + Quick quiz 1개 + 접힌 "More drills". **한 화면** |
| Speak | 오늘 할 것 3개 + 버디 세션 |
| Guide | 참조 탭(한자 40뿌리 브라우저 포함) — 밀도는 성격상 당연 |

**측정 함정 하나 기록**: 처음엔 Practice가 42개 선택지로 나왔는데, 닫힌 `<details>` 안의 `<select>`가
`offsetHeight`를 보고해서 생긴 착시였다. 실제 `<details>`는 접혀 있다(높이 58px). 화면을 직접 보고서야 알았다.

**진짜 문제는 레슨 한 편의 길이였다.**

| 실측 | 값 |
|---|---|
| 챕터당 화면 수 | 최소 21 · **중앙값 24** · 최대 29 |
| 1과 | **23화면** (새 단어 17개 → 6화면, 문법 2, 대화·읽기·문화 3, **연습 11**, 쓰기·말하기 2) |
| 브라우저 실측 | `Words 1/6` → … → `Practice 1/12` |

홈은 "10 minutes for today"라고 하는데 첫 레슨이 23화면이다. 30~45분짜리 교재 단원이고,
**중간에 멈추면 "끝냈다"가 아니라 "포기했다"가 된다.** 사용자가 말한 "뭔가 쉽지 않다"의 실체로 보인다.

## 구현

내용은 줄이지 않았다(사용자가 내용은 괜찮다고 했고, 실제로 좋다). 대신 **이미 있는 이음매를 표시**했다:
가르치는 구간(단어·문법·대화)이 끝나고 훈련 구간(연습·쓰기·말하기)이 시작되는 자리.

### `src/lib/lessonSessions.js` (신설, TDD)
- `sessionBreakAt(screens)` — 첫 비-교습 화면의 인덱스. 단, **넣지 않는 경우**를 명시:
  - 앞의 교습 화면이 3개 미만(첫 세션이라 부를 게 없음)
  - 남은 화면이 6개 미만(중단시키는 게 그냥 끝내는 것보다 성가심)
  - 교습 구간 없이 훈련만 있는 경우
- `withSessionBreak(screens)` — 이음매에 브레이크 화면 1장 삽입. **다른 화면은 하나도 건드리지 않는다**(테스트로 고정).
- `sessionSummary(screens)` — "words, grammar and the dialogue"처럼 방금 뭘 했는지 문장으로.

### `SessionBreak.svelte`
"Good place to stop / You've covered words, grammar and the dialogue. / 12 screens of practice and
speaking are left — do them now while it's fresh, or come back later and pick up right here."
→ **[Finish for today]** + "Or keep going below."

**벽이 아니라 쉼표다.** Next 버튼은 그대로 있고 아무것도 막지 않는다. 브레이크 화면에서는 상단 phase 태그를
숨겼다(“PRACTICE / 여기서 멈추세요”는 서로 어긋나 읽힌다).

### 재개 지점 (브라우저 QA가 잡아낸 버그)
처음 구현에서 "Finish for today"가 현재 인덱스(=브레이크 화면)를 저장해서, **돌아오면 "여기서 멈추세요"가
첫 화면**으로 떴다. 시작하자마자 그만두라는 말이 된다. `stopForToday()`가 `i + 1`을 저장하도록 고쳤다.
검증: 정지 시 `{"chapter-01":{"index":12}}` 저장 → 재개하면 `Practice 2/12`(연습 첫 문제)로 바로 진입.

## 검증
- `lessonSessions.test.js` 9개: 이음매 위치 / 짧은 레슨엔 미삽입 / 교습 구간 없으면 미삽입 /
  첫 세션이 1화면이면 미삽입 / **정확히 1장만 삽입되고 나머지 배열은 불변** / 남은 화면 수 / 요약 문구.
  픽스처가 규칙보다 짧아 첫 케이스가 어긋났고, 규칙이 옳으므로 픽스처를 현실적 길이로 고쳤다.
- 브라우저 QA(375px): 1과에서 11번째 화면에 브레이크 렌더 → "Finish for today" → 홈이 "Continue Chapter 1"
  → 재개 시 브레이크 건너뛰고 연습 진입.

## 하지 않은 것
- 내용 삭제·축소(사용자 판단: 내용은 괜찮다).
- 세션을 강제로 끊기(잠금 없음 원칙 — 브레이크는 *초대*지 *제한*이 아니다).
- 홈/Practice 화면 재설계(실측 결과 이미 단순하다 — 손댈 이유가 없었다).
- Guide 탭 정리(참조 탭이라 밀도가 성격상 자연스럽다. 필요하면 별건).
