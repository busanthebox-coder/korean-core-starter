# S3 — 화면당 결정 1개: Practice·Speak·Guide 첫 화면 단순화

규모: 중(UI 중심). 의존: **S2 필수**(learnerLevel·recommended 덱을 그대로 사용).
목표 한 줄: 신규 사용자가 어느 탭을 열어도 "다음 하나"가 먼저 보이고, 옵션은 접혀 있게.

## 실측 근거 (2026-07-20, 신규 사용자 · 375px)
- Practice: 탭 가능 요소 **39개** 동시 노출(덱 선택 × 종류 4 × 모드 × 활용 옵션).
- Speak: 2.8 화면, 6개 섹션 — 1일차에 은행 롤플레이 + 버디 미션 + 라이브러리 2종.
- Guide: 6.2 화면 — 신급자 첫 화면에 한자 어근 패밀리(間) 노출.
- 반면 Learn은 9개/1화면으로 양호 — **Learn의 "오늘 카드 하나" 패턴이 이 트랙의 표준**이다.

## 구현

### Part A. Practice — "오늘의 복습" 히어로 + 옵션 폴드
1. 첫 화면 구성(위→아래):
   - **히어로 카드 1개**: due 있으면 "복습 N개 — 시작"(원탭), 없으면 "새 연습 시작"(S2 recommended 덱).
     Learn의 TODAY 카드와 같은 시각 문법(.btn3d 주황 버튼 1개).
   - 약점(weak) 항목이 있으면 보조 카드 1개(있을 때만 렌더).
   - **그 외 전부** — 덱 선택·종류(단어/표현/패턴)·활용 드릴·레벨 옵션 — `<details>` "다른 연습 고르기"로 접기.
     기본 접힘. 열면 기존 UI 그대로(기능 제거 아님 — 재배치).
2. 첫 화면 탭 가능 요소 목표: **≤ 8** (실측 39 → 8). 테스트로 상한 고정(렌더 후 카운트).
3. 딥링크(`#/practice?deck=...`)는 기존 동작 유지 — 접힘 상태여도 링크 진입 시 해당 덱 자동 선택+펼침.

### Part B. Speak — 오늘 3단계만 첫 화면에
1. 첫 화면 = 기존 "1 Say-it / 2 Listen&repeat / 3 Respond" 3카드(이미 좋음) + **주간 버디 1줄 요약 칩**
   ("이번 주 친구와 · 미션 2/3 남음" — 탭하면 스크롤).
2. 버디 세션 상세(3미션+3단계 안내)와 라이브러리 선택은 **접힌 섹션**으로 하강.
   라이브러리 2버튼(Browse listen-and-repeat / Browse roleplays)은 "라이브러리" `<details>` 하나로 통합.
3. 추천 3종은 S2 게이트를 이미 통과한 상태(여기선 UI만).
4. 첫 화면 높이 목표: **1.5 화면 이내**(실측 2.8).

### Part C. Guide — 레벨별 점진 노출
1. 신규(A1) 첫 화면: App Manual 트랙 + 생존/생활 트랙 상단 고정. **한자 어근 패밀리·B급 트랙은
   learnerLevel ≥ A2부터 렌더**(그 전엔 "더 많은 자료가 레벨에 맞춰 열립니다" 1줄 안내로 존재만 알림).
2. 내가 쓴 글(쓰기 기록)·백업 카드는 유지(행동 유도가 아니라 자산이므로).
3. 첫 화면 높이 목표: **3 화면 이내**(실측 6.2).

### Part D. 공통 마감
1. 세 탭 모두: 접힘/펼침 상태는 저장하지 않는다(세션마다 접힘 기본 — "심플이 기본값").
2. 시각 회귀 확인: Hanmok 토큰·카드 스타일 변경 없음(diff에 tokens.css 등장하면 잘못된 것).
3. 접근성: `<details>/<summary>` 기본 시맨틱 유지, 히어로 버튼 키보드 도달 확인.

## 수용 기준
1. 신규 사용자 실측 재현: Practice 첫 화면 탭 요소 ≤8 / Speak ≤10·1.5화면 / Guide 3화면 이내
   (같은 측정 스크립트로 before/after 수치를 완료 기록에 표로).
2. 기존 기능 전부 접근 가능(폴드 안에서) — 덱·종류·활용·라이브러리 각 1회 E2E.
3. 딥링크 회귀 없음. 4. 테스트 green + build + lint:content. 브라우저 QA 375px + 데스크톱 1280.
